# SimpleNexus (now nCino Mortgage)

> SimpleNexus was a mobile-first homeownership / mortgage platform (backed by Insight Partners) acquired by nCino. Its product is now delivered as the nCino Mortgage Suite, and its developer API — explicitly built to "replace the legacy SimpleNexus API" — is published as the nCino Mortgage API. The API covers Organization & User Management (companies, branches, users) and a modern webhook flow, secured with OAuth 2.0.

## APIs
- [nCino Mortgage API (formerly SimpleNexus API)](https://developer.ncinomortgage.com/mortgage): OAuth 2.0 REST API; base URL https://api.ncinomortgage.com. Initial release covers company administration, user provisioning, branch management, and webhook management.
